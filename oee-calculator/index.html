02Worked example

One 8-hour shift. 480 min shift, 60 min of planned breaks, 47 min of unplanned downtime, 1.0 s ideal cycle, 19,271 parts made, 18,848 good.

  • Availability = 373 / 420 = 88.8%
  • Performance = 19,271 s / 22,380 s = 86.1%
  • Quality = 18,848 / 19,271 = 97.8%
  • OEE = 0.888 × 0.861 × 0.978 = 74.8%

In hours, speed loss (0.86 h) is slightly bigger than downtime (0.78 h), so small stops and slow cycles deserve as much attention as breakdowns.

03How it works

OEE multiplies three ratios. Each one measures a different kind of loss:

Planned time = shift - planned stops Run time = planned time - unplanned downtime Availability = run time / planned time Performance = (ideal cycle time × total parts) / run time Quality = good parts / total parts OEE = availability × performance × quality

The bars turn each loss into hours. Availability loss is breakdowns, changeovers and waiting for material. Speed loss is time when the machine ran but slower than ideal, including small stops nobody logs. Quality loss is the machine time spent making scrap and rework. Fully productive time is what is left: good parts made at ideal speed.

Use the fastest cycle time the machine can sustain as the ideal cycle time, not the standard from the routing. If performance comes out above 100%, the ideal is set too slow.

04FAQ

What is a good OEE score?

85% is often quoted as world class for discrete manufacturing. Many plants are between 40% and 60% when they start measuring honestly. Your own trend matters more than a benchmark.

Should breaks count as downtime?

No. Planned stops such as breaks and scheduled meetings come out of the shift before availability is calculated. Some plants use 'TEEP' when they want to count all calendar time.

Do changeovers count as downtime?

Yes, in standard OEE a changeover is an availability loss. Recording it separately from breakdowns helps you see whether SMED work is worth doing.

Why is my performance over 100%?

The ideal cycle time is set slower than the machine really runs. Use the fastest proven cycle time, not a planning standard that includes allowances.

What counts as a good part?

Only parts that are right the first time. Reworked parts count as quality loss even if they ship in the end.

Is my data uploaded anywhere?

No. Everything is calculated in your browser.
